About
 MoodWave
 Platform

A mood-adaptive music streaming platform built with Node.js, Express, and an advanced MySQL database — designed to match music to your current emotion, in real time.

Tech Stack
🌐
HTML · CSS · JS
Vanilla frontend with Web Audio API for real-time visualizations and full offline fallback support.
⚙️
Node.js & Express
RESTful API backend serving songs, analytics, recommendations, and live stream data.
🗄️
MySQL 8.0
Advanced schema with 6 tables, 2 views, 2 stored procedures, 1 trigger, and composite indexes.
🎵
Last.fm & YouTube
Track metadata via Last.fm API. YouTube audio streaming via yt-search and ytdl-core proxying.
Features
🎭
6 Mood Playlists
Happy, Chill, Sad, Energetic, Focus, Night — each with a uniquely themed player page.
🎛️
Mood Player
Toggle multiple moods and generate a combined cross-mood playlist on the fly.
📊
Audio Visualizer
Real-time frequency bar visualizer reacting to every beat using the Web Audio API.
🔍
Discover
Search any song via Last.fm and stream audio directly from YouTube.
📺
Live Stage
Embedded YouTube live streams from the database, plus paste any URL to stream instantly.
⚡
Instant Fallback
Works online and offline. When backend is unavailable, songs load from local JSON files.
