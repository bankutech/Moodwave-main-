# MoodWave Backend

This is the Node.js backend for MoodWave.

## Requirements
- Node.js (v16+)
- MySQL (v8.0+)

## Getting Started
1. Run `npm install` to install dependencies.
2. Initialize the MySQL database using the `database.sql` script located in the project root.
3. Start the server using `npm run start` or `node server.js`.

## Advanced Features
This backend connects to a MySQL database using a connection pool and includes support for views and stored procedures for advanced analytics.
